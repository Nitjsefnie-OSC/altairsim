# National AN-493 — the INS8250, NS16450 and NS16550AF compared

Source: [NS16450.PDF](#)

National Semiconductor **Application Note 493**, *A Comparison of the INS8250, NS16450 and
NS16550AF Series of UARTs*, Martin S. Michael, April 1989 (© 1995 printing, Lit. # 100493,
TL/C/9320), 8 PDF pages. It says how the seven parts of the 8250 family **differ** in function
and timing.

**This is not a data sheet, whatever the file is named.** It has **no register map, no bit
tables, no reset-state table and no pin descriptions**. It assumes the reader has the data
sheet. Use it to decide *which* 8250 behavior a board needs; the register layout is in
[National INS8250A / NS16450](INS8250.md), which is the data sheet for the later parts.

**Not emulated** — no 8250 chip model exists. This file omits the bus-timing rows of the AC
tables (setup, hold and strobe widths in nanoseconds, pp. 4–5), which no emulator needs.

**Scan notes.** Clean text layer; the tables were still read as page images. Pages 4–6 (the AC
tables) are rotated. Page 7 is blank.

## 1. Quick reference for emulation

| Question | INS8250, INS8250-B | INS8250A, NS16450 (and CMOS INS82C50A, NS16C450) |
|---|---|---|
| Register at offset 7 (`111`) | **None** | One-byte scratch pad register |
| INTR with several interrupts pending | **Pulses low** after each one is serviced | **Stays high** until all are serviced (level) |
| Line status bit 6 (TSRE / TEMT) | 1 as soon as the **shift register** empties, even if the holding register is full | 1 only when the holding register **and** the shift register are empty |
| Modem outputs in loopback | RTS*, DTR*, OUT1*, OUT2* **stay connected** to the modem control bits | Forced to their inactive state (logic 1) |
| Baud divisor | 1 to 2¹⁶ − 1 | same |

The NS16550AF powers up as an NS16450 and adds FIFOs (§4).

## 2. The seven parts (§1.0, p. 1)

| Part | What it is |
|---|---|
| **INS8250** | The original. Same part as the INS8250-B with faster CPU bus timing |
| **INS8250-B** | The slower bus-timing version. "Used by many popular 8088-based microcomputers" |
| **INS8250A** | A redesign of the INS8250 on the XMOS process. Used in 8086-based machines |
| **NS16450** | The faster bus-timing version of the INS8250A. Used in 80286-based machines |
| **NS16550AF** | Powers up in NS16450 mode; adds working FIFOs, a DMA interface, a higher maximum baud rate |
| NS16550 | Limited issue. Its FIFOs are "essentially non-functional"; use the NS16550AF |
| INS82C50A, NS16C450 | CMOS versions of the INS8250A and NS16450. Function is identical |

The XMOS and CMOS parts are **not** drop-in replacements for the INS8250 / INS8250-B in a
machine whose interrupt controller is edge-triggered (§5).

## 3. Behavior by part

### 3.1 INS8250 and INS8250-B (§2.0, pp. 1–2)

1. With several interrupts pending, **INTR pulses low after each interrupt** instead of staying
   high. An edge-triggered interrupt controller depends on this.
2. **Line status bit 6 (TSRE)** is set as soon as the transmitter shift register empties,
   **whether or not the holding register holds a character**. It is reset when the shift
   register is reloaded. Some 8088 diagnostic programs test this.
3. **In loopback mode** the outputs RTS*, DTR*, OUT1* and OUT2* remain connected to their modem
   control register bits.

### 3.2 INS8250A and NS16450 (§3.0, p. 2)

1. Loopback sets RTS*, DTR*, OUT1* and OUT2* to their inactive state (logic 1), so no false
   signals go out.
2. A **one-byte scratch pad register** is at location `111`. "This register is not on the
   INS8250 or -B."
3. With several interrupts pending, **INTR stays high**. The interrupts are level-sensitive.
4. **Line status bit 6** is 1 when **both** the holding register and the shift register are
   empty. This makes these parts "incompatible with some INS8250 software utilizing this bit".

Timing (§3.1):

1. A start bit is sent typically 16 clocks (1 bit time) after the write to the holding register.
2. The leading edge of that write resets THRE and TEMT.
3. All the line status error flags and Data Ready are set during the first stop bit.
4. TEMT is set 2 RCLK periods after the stop bit or bits are sent.
5. The modem control register updates the modem outputs on the trailing edge of the write.

### 3.3 CMOS parts (§4.0, p. 2)

Everything in §3.2 applies, plus: after any reset pulse **the divisor latches must be written
again** to start the baud generator, and `tSI` is 16 to 48 RCLK cycles.

## 4. NS16550AF and NS16550 (§5.0, p. 2)

- §3.2 applies to both.
- The NS16550 sometimes transfers extra characters when the CPU reads the receive FIFO. There
  is no work-around; do not use its FIFO mode.
- **Telling them apart:** with the FIFOs enabled (bit 0 of the FIFO control register set),
  **IIR bit 7** is 1 on both parts; **IIR bit 6** is 1 on the NS16550AF and permanently 0 on the
  NS16550. Use the FIFOs only when both bits are 1.

## 5. Edge-triggered interrupt controllers (§6.0, p. 3)

Software written for the INS8250-B may rely on items 1 and 2 of §3.1. On the later parts, with
an edge-triggered controller and more than one interrupt pending, INTR stays high and no new
edge arrives. Two fixes:

- **Software:** before leaving the interrupt handler, write `00h` to the interrupt enable
  register, then write back the wanted enable bits.
- **Hardware:** AND the UART's INTR with a signal that goes low on every access to the UART
  (the note's figure uses IOR*). This makes one invalid interrupt, which the software must
  tolerate.

A system that **polls** the UART has no such problem; every later part then replaces the
INS8250-B directly.

## 6. Delays that are counted in bit-clock cycles (pp. 5–6)

A "baudout cycle" is one cycle of the 16× clock; 16 make a bit time.

| Symbol | Parameter | NS16550AF | NS16450 | INS8250A | INS8250 / -B |
|---|---|---|---|---|---|
| `tIRS` | Initial INTR reset to transmit start | 8–24 | 24–40 | 24–40 | max 16 |
| `tSI` | Initial write to interrupt | 16–24 | 16–24 | 16–24 | max 50 |
| `tSTI` | Stop bit to THRE interrupt | 8 | 8 | 8 | max 8 |
| `tSINT` | Stop bit to receive interrupt set | 1 RCLK | 1 RCLK | 1 RCLK | 2000 ns |
| `tSCD` | RCLK to sample time | 2000 ns | 2000 ns | 2000 ns | 2000 ns |

`tSI` and `tSTI` grow by one character time less the last stop bit when the transmitter
interrupt delay circuit is active (note 7).

The figure on p. 1 shows a typical connection with a 3.072 MHz crystal; serial data is start
bit, 5–8 data bits, parity, stop (Figure 2).

## Quirks worth carrying

- ⚠ **The file name promises an NS16450 data sheet; the content is an application note.** No
  register can be implemented from it.
- ⚠ **"8250" is three different behaviors.** Before modeling one, find out which part the board
  carried: original (§3.1) or A / 16450 (§3.2). The scratch register, the TSRE bit and the INTR
  shape all change.
- ⚠ **Offset 7 does not exist on the original INS8250.** Software that tests for a scratch
  register is testing for the later part.
- ⚠ **Line status bit 6 means two different things** (§1). Software that waits on it for "safe
  to send" works on the original part and can wait a full character longer on the later ones.
- ⚠ On the CMOS parts a reset stops the baud generator until the divisor is rewritten.
