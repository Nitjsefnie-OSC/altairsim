# National INS8250A / NS16450 — UART (the 8250 family data sheet)

Source: [INS8250.PDF](#)

National Semiconductor, *PC16450C/NS16450, PC8250A/INS8250A Universal Asynchronous
Receiver/Transmitter*, data sheet dated **July 1990** (TL/C/8401, Lit. # 112903), 18 PDF pages.
The 40-pin UART with a built-in baud generator, modem control lines and a four-level
prioritized interrupt: the register map, every bit, the reset state, the interrupt table and the
divisor tables.

**Which part this is.** The file is named `INS8250`, but the sheet covers the **INS8250A and
NS16450** (and their `PC` namesakes) — the redesigned parts. The **original INS8250 and
INS8250-B** behave differently in four places (scratch register, INTR, line status bit 6,
loopback outputs); those differences are in [National AN-493](NS16450.md) §1. Everything else
here — the register addresses and bit layouts — is common to the family.

**Not emulated** — no 8250 chip model exists. One board in `reference/` uses the chip: the
[CCS Model 2810](California%20Computer%20Systems%202810%20CPU%20Manual.md). This file omits the
DC and AC electrical tables (pp. 3–5), the bus timing waveforms (pp. 6–7) and the package
drawings (pp. 17–18).

**Scan notes.** No text layer (each page carries only a distributor's footer line) — every page
was read as an image. PDF page = printed page. The typical-application drawing (p. 16) is
rotated.

## 1. Quick reference for emulation

| Item | Value |
|---|---|
| Address inputs | A0–A2: eight register addresses. Two more registers share offsets 0 and 1 through `DLAB` (LCR bit 7) |
| Select | CS0 = 1 **and** CS1 = 1 **and** CS2* = 0 |
| Strobes | Read: RD high **or** RD* low. Write: WR high **or** WR* low. Only one of each pair is needed |
| Baud | `divisor = clock / (baud × 16)`, 16 bits, 1 to 2¹⁶ − 1. Divisor 0 "is not recommended" |
| Format | 5, 6, 7 or 8 data bits; even, odd, stick or no parity; 1, 1½ or 2 stop bits |
| Bit order | Bit 0 is sent and received first |
| Interrupt | One INTR output, active high; four sources, fixed priority (§6) |
| Reset (MR high) | IER `00h`, IIR `01h`, LCR `00h`, MCR `00h`, LSR `60h`, MSR `x0h`; the divisor, receiver buffer and holding register are **not** reset |
| Modem pins | All active low. A 1 in an MCR bit drives its pin low; an MSR level bit is the **complement** of its pin |

## 3. Reset (Table I, p. 10)

| Register / signal | Reset by | State |
|---|---|---|
| Interrupt Enable | Master Reset | `0000 0000` (bits 7–4 permanently 0) |
| Interrupt Identification | Master Reset | `0000 0001` (bits 7–3 permanently 0) |
| Line Control | Master Reset | `0000 0000` |
| MODEM Control | Master Reset | `0000 0000` (bits 7–5 permanently 0) |
| Line Status | Master Reset | `0110 0000` (bit 7 permanently 0) |
| MODEM Status | Master Reset | `xxxx 0000` — bits 7–4 follow the input pins |
| SOUT | Master Reset | High (marking) |
| INTR, receiver errors | Read LSR, or MR | Low |
| INTR, received data ready | Read RBR, or MR | Low |
| INTR, THRE | Read IIR, or write THR, or MR | Low |
| INTR, modem status change | Read MSR, or MR | Low |
| OUT 2*, RTS*, DTR*, OUT 1* | Master Reset | High (inactive) |

Master Reset clears "all the registers (except the Receiver Buffer, Transmitter Holding, and
Divisor Latches)" (p. 9).

## 4. Line Control Register — offset 3 (§8.1, pp. 11–12)

| Bit | Meaning |
|---|---|
| 1, 0 | Character length: `00` 5 bits, `01` 6, `10` 7, `11` 8 |
| 2 | Stop bits. 0 = 1. 1 = 1½ with a 5-bit word, 2 with 6, 7 or 8. **The receiver checks the first stop bit only**, whatever this bit says |
| 3 | Parity enable: a parity bit is sent, and checked on receive, between the last data bit and the stop bit |
| 4 | With bit 3 = 1: 0 = odd parity, 1 = even |
| 5 | Stick parity. With bits 3 and 5 = 1: bit 4 = 1 sends and checks the parity bit as **0**; bit 4 = 0 sends and checks it as **1**. Bit 5 = 0 disables it |
| 6 | Break control. 1 forces SOUT to spacing (0). It acts only on SOUT; the transmitter logic keeps running |
| 7 | DLAB. 1 = offsets 0 and 1 are the divisor latches. 0 = receiver buffer, holding register, interrupt enable |

The register reads back what was written.

To send a clean break (note, p. 12): load an all-zeros pad character when THRE is set; set
break after the next THRE; wait for TEMT = 1; clear break.

## 5. Line Status Register — offset 5 (§8.4, p. 13)

| Bit | Name | Set | Cleared |
|---|---|---|---|
| 0 | DR | A complete character has moved into the receiver buffer | Reading the receiver buffer |
| 1 | OE | The buffer was not read before the next character moved in; the earlier character is lost | Reading the LSR |
| 2 | PE | The received character's parity is wrong for the selected parity | Reading the LSR |
| 3 | FE | The stop bit after the last data or parity bit was 0 (spacing) | Reading the LSR |
| 4 | BI | The input stayed spacing longer than a full word (start + data + parity + stop) | Reading the LSR |
| 5 | THRE | A character moved from the holding register to the shift register | Loading the holding register |
| 6 | TEMT | The holding register **and** the shift register are both empty | Either one holds a character |
| 7 | — | Permanently 0 | |

- Bits 1–4 are the conditions that raise the Receiver Line Status interrupt.
- After a framing error the UART tries to resynchronize: it treats the bad stop bit as the next
  start bit, samples it twice and takes in the "data" that follows.
- After a break, the input must return to 1 for at least half a bit time before the next
  character can start.
- THRE also raises the THRE interrupt when that interrupt is enabled.
- ⚠ **Writing the LSR**: "intended for read operations only. Writing to this register is not
  recommended as this operation is only used for factory testing." So it *is* writable.
- ⚠ Bit 6 here is the INS8250A / NS16450 definition. On the original INS8250 it follows the
  shift register alone ([AN-493](NS16450.md) §3.1).

## 6. Interrupts (§8.5–8.6, Table IV, pp. 13–14)

**Interrupt Enable Register — offset 1.** A 1 enables the source: bit 0 received data
available, bit 1 holding register empty, bit 2 receiver line status, bit 3 modem status. Bits
4–7 are always 0. A disabled source does not show in the IIR and does not raise INTR; the LSR
and MSR bits still work normally.

**Interrupt Identification Register — offset 2, read only.** Bit 0 = 0 means an interrupt is
pending. Bits 3–7 are always 0.

| IIR value | Bits 2 1 0 | Priority | Type | Source | Cleared by |
|---|---|---|---|---|---|
| `01h` | 0 0 1 | — | None | — | — |
| `06h` | 1 1 0 | Highest | Receiver line status | Overrun, parity or framing error, or break | Reading the LSR |
| `04h` | 1 0 0 | Second | Received data available | Receiver data available | Reading the receiver buffer |
| `02h` | 0 1 0 | Third | Holding register empty | THRE | Reading the IIR (if it is the source), or writing the holding register |
| `00h` | 0 0 0 | Fourth | Modem status | CTS, DSR, RI or DCD | Reading the MSR |

While the CPU reads the IIR, the chip freezes it at the highest pending source; new interrupts
are recorded but do not change the value until the read ends.

INTR is high whenever an enabled source is active, and goes low after the matching service
action or a Master Reset. ⚠ On the original INS8250 it pulses low between pending interrupts
instead ([AN-493](NS16450.md) §3.1).

## 7. MODEM Control Register — offset 4 (§8.7, p. 14)

| Bit | Name | Effect |
|---|---|---|
| 0 | DTR | 1 drives the DTR* pin low (active); 0 drives it high |
| 1 | RTS | Same, for RTS* |
| 2 | OUT 1 | Same, for the user output OUT 1* |
| 3 | OUT 2 | Same, for the user output OUT 2* |
| 4 | Loop | Local loopback (below) |
| 5–7 | — | Permanently 0 |

The outputs are meant to go through an inverting line driver, so a 1 in the bit puts the
asserted level on the RS-232 line.

**Loopback (bit 4 = 1):**

- SOUT goes to marking (1); SIN is disconnected.
- The transmitter shift register's output feeds the receiver shift register's input.
- The four modem **inputs** (DSR*, CTS*, RI*, DCD*) are disconnected.
- The four modem control **bits** drive the four modem status inputs internally: RTS → CTS,
  DTR → DSR, OUT 1 → RI, OUT 2 → DCD.
- The four modem output **pins** are forced inactive (high). ⚠ On the original INS8250 they
  stay connected ([AN-493](NS16450.md) §3.1).
- Receiver, transmitter and modem interrupts all still work, under the IER. The modem status
  interrupts then come from the low four bits of the MCR.

## 8. MODEM Status Register — offset 6 (§8.8, pp. 14–15)

| Bit | Name | Meaning |
|---|---|---|
| 0 | DCTS | CTS* changed since the MSR was last read |
| 1 | DDSR | DSR* changed since the MSR was last read |
| 2 | TERI | RI* went from low to high (the trailing edge of a ring) |
| 3 | DDCD | DCD* changed since the MSR was last read |
| 4 | CTS | Complement of the CTS* pin. In loopback = MCR RTS |
| 5 | DSR | Complement of the DSR* pin. In loopback = MCR DTR |
| 6 | RI | Complement of the RI* pin. In loopback = MCR OUT 1 |
| 7 | DCD | Complement of the DCD* pin. In loopback = MCR OUT 2 |

- Bits 0–3 are set by a change and **cleared by reading the MSR**. Any of them set raises the
  modem status interrupt, if enabled.
- TERI is one-way: it records RI* rising only, where the other three record any change.
- CTS* "has no effect on the Transmitter" and DCD* "has no effect on the receiver" (p. 9). The
  chip does no automatic flow control.

## 9. Scratchpad — offset 7 (§8.9, p. 15)

One read/write byte that "does not control the UART in any way". Not present on the original
INS8250 or INS8250-B ([AN-493](NS16450.md) §3.2).

## 10. Baud generator (§8.3, Table III, pp. 12–13)

- Clock in from DC to 8 MHz, crystal on XIN/XOUT or an external clock on XIN.
- `divisor = clock / (baud × 16)`. The output, BAUDOUT*, is 16 × the baud rate and clocks the
  transmitter. **The receiver has its own 16× clock input, RCLK**; tying BAUDOUT* to RCLK
  gives one rate for both.
- **Loading either divisor latch immediately reloads the 16-bit baud counter.**
- The divisor must be loaded during initialization.

## Quirks worth carrying

- ⚠ **This sheet is the INS8250A / NS16450, not the original INS8250.** For a 1970s or
  early-1980s board, check [AN-493](NS16450.md) before using the scratch register, LSR bit 6,
  the INTR level or the loopback output behavior from here.
- ⚠ **IIR bit 0 is inverted**: 0 means pending. The idle value is `01h`.
- ⚠ **Reading the IIR clears a THRE interrupt** — but only when THRE is the source it reports.
- ⚠ **LSR resets to `60h`**, not 0: the transmitter is empty at reset.
- ⚠ **MSR level bits are complements of active-low pins**, so a bit reads 1 when the pin is low.
  The delta bits clear on every MSR read, and TERI catches one edge only.
- ⚠ **The receiver and transmitter clocks are separate pins.** A board need not run them at the
  same rate.
- ⚠ **The divisor survives a reset**, and writing either half restarts the counter.
- ⚠ The chip never gates the transmitter on CTS or the receiver on DCD; any flow control is the
  software's.
- ⚠ The LSR can be written (a factory-test path). At least one monitor does it: the CCS 2810's
  MOSS 2.2 writes 0 there to clear the flags.
